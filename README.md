# Lab 3: Agentic RAG with Safety Measures

## 📋 Overview

An advanced Retrieval-Augmented Generation (RAG) system with multi-agent architecture and comprehensive safety measures. This system answers complex queries using an external knowledge base while ensuring safety, reliability, and accuracy.

**[📄 READ THE FULL SYSTEM REPORT (Architecture & Safety)](REPORT.md)**

## 🚀 Key Features

*   **Multi-Agent Architecture**: Orchestrator, Maker, Checker, and Retriever agents working in harmony.
*   **Safety First**: Input validation, output sanitization, and content moderation.
*   **Quality Assurance**: Iterative Maker-Checker loop to refine answers.
*   **Demo**: [Run the Interactive Demo Notebook](notebooks/assignment_demo.ipynb)

## 🎯 Objectives
1. Design and implement an agentic RAG system with specialized agents
2. Implement multi-layer safety mechanisms
3. Create a maker-checker loop for quality assurance
4. Ensure reliable and safe responses to user queries
